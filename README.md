# ☀️ Sky-Cast — Weather Application

A modern and responsive weather application built with **React** and **Vite** that provides real-time weather updates for any city worldwide with a clean glassmorphism-inspired UI.

---

## ✨ Features

- 🔍 **City Search** — Search weather details by city name
- 🌡️ **Real-Time Weather Data** — Get live temperature, humidity, and weather conditions
- 🎨 **Modern UI** — Beautiful glassmorphism design with smooth animations
- 📱 **Responsive Design** — Optimized for desktop, tablet, and mobile devices
- 🌙 **Dark Theme** — Eye-friendly modern dark interface
- 🔄 **Dynamic Weather Icons** — Weather visuals update based on conditions
- ⚡ **Fast Performance** — Powered by Vite for lightning-fast loading

---

## 🛠️ Tech Stack

- **Frontend:** React 19
- **UI Library:** Material UI (MUI)
- **Build Tool:** Vite
- **Styling:** CSS3 with Glassmorphism Effects
- **Icons:** Lucide React
- **API:** OpenWeather API
- **Deployment:** Vercel

## 📦 Installation & Setup

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/sky-cast.git
cd sky-cast
```

### 2️⃣ Install Dependencies

```bash
npm install
```

### 3️⃣ Create Environment Variables

Create a `.env` file in the root directory:

```env
VITE_API_KEY=your_openweather_api_key
```

Get your free API key from:

https://openweathermap.org/api

### 4️⃣ Start Development Server

```bash
npm run dev
```

### 5️⃣ Open in Browser

```bash
http://localhost:5173
```

---

## 🚀 Build & Deployment

### Build for Production

```bash
npm run build
```

### Preview Production Build


## 🌐 Deploy on Vercel

1. Push your project to GitHub
2. Import the repository into Vercel
3. Add the environment variable:

```env
VITE_API_KEY=your_openweather_api_key
```

4. Click **Deploy** ✅

## 📖 Usage

1. Enter a city name in the search box
2. Click the **Search** button
3. View detailed weather information including:

- 🌡️ Current Temperature
- 💧 Humidity
- 🤒 Feels Like Temperature
- 📉 Minimum Temperature
- 📈 Maximum Temperature
- 🌤️ Weather Description
